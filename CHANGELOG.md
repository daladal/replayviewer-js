# Changelog

## 1.0.0 — 2026-09-19

- Storyboard and video support; opt in with `storyboard: true` / `video: true` on `createReplaySession`
- Realign osu!standard playfield to correctly line up with storyboard objects
- Add mirror mod support for osu!standard
- Support lazer style mod icons
- Fix custom beatmap hitsounds not resolving correctly
- Allow taiko flying hit animation to be toggled via `RenderOptions.taikoFlyingHits`
- Various performance improvements
